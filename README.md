# Bank Loan Analysis Dashboard | Power BI

An interactive Power BI report designed to explore bank loan data and communicate lending-related performance through visual summaries.

## Project overview
The report contains multiple pages, including **Summary** and **Overview**, to help examine the loan portfolio from different perspectives.

## Tools
- Microsoft Power BI
- Data visualization
- Interactive report design

## Report file
The Power BI report is available as `project 2.pbix`.

## How to use
Download `project 2.pbix` and open it in Power BI Desktop.

## Purpose
Demonstrate dashboard design and business analysis using financial lending data.
